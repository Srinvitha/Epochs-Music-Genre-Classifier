# Epochs External Knowledge Source Manifest

This folder contains curated, source-attributed study notes, not a mirror of complete external books or manuals. It is a first external-knowledge layer for Epochs' RAG while the classifier remains on FMA Small's eight labels.

## Open Music Theory
- URL: https://openmusictheory.github.io/
- Relevant topics: rhythm, meter, harmony, chord progressions, form, pop/rock music, orchestration and post-tonal concepts.
- License: CC BY-SA 4.0, except where individual pages indicate otherwise.
- Use in this pack: original concise summaries, not verbatim reproduction.
- Attribution: Open Music Theory, by Mark Gotham, Kyle Gullings, Chelsey Hamm, Bryn Hughes, Brian Jarvis, Megan Lavengood, and John Peterson; edited by Erin K. Maher, with other contributors. See the source site for full credits.
- References: https://openmusictheory.github.io/contents.html and https://openmusictheory.github.io/about.html

## REAPER User Guide and ReaEffects Guide
- URL: https://www.reaper.fm/userguide.php
- Relevant topics: recording, editing, mixing, audio/MIDI processing and troubleshooting in REAPER.
- Usage note: the official site offers downloadable manuals, but availability does not automatically permit copying or redistribution of the complete text. This pack does not reproduce the manual. Use it as a linked reference and label any tool-specific instructions.

## SuperCollider Help and tutorials
- Docs: https://docs.supercollider.online/
- Official tutorial repository: https://github.com/supercollider/learn
- Help documentation license: CC BY-SA 3.0 Unported, unless a page says otherwise. The tutorial repository states CC BY-SA 4.0 for its content.
- Relevant topics: synthesis, oscillators, filters, envelopes, modulation, effects, algorithmic composition and procedural sound.
- Use in this pack: original summaries, not copied complete help pages.
- Note: SuperCollider executable code/software has separate GPL licensing; documentation and code should not be assumed to share the same license.
