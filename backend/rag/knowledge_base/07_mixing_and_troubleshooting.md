# Mixing and Troubleshooting — Practical Checklist

## Diagnose before prescribing
The RAG has not heard a track unless actual audio analysis is available. Use conditional language (“try checking…”) and ask for a description or measured data when needed. Do not invent exact EQ frequencies, compression values, or source instruments.

## Muddy mix
1. Mute layers to identify which ones create buildup.
2. Check overlapping bass and low-mid roles.
3. Shorten or automate long reverb tails if they mask the next sound.
4. Simplify voicings or remove a layer before applying more processing.
5. Compare at matched loudness.

## Harsh or tiring sound
1. Check bright layers and accumulated distortion.
2. Listen for resonances in individual sounds.
3. Reduce excessive high-frequency energy only where needed.
4. Compare processed and unprocessed versions at similar loudness.

## Weak or unclear low end
1. Check whether kick and bass compete rhythmically.
2. Check phase and mono compatibility.
3. Decide which element supplies sub-bass and which supplies attack or midrange.
4. Check playback on more than one listening system if possible.

## Flat arrangement
1. Identify the most important moment.
2. Remove an element before that moment to create contrast.
3. Automate one meaningful parameter.
4. Change register, rhythm density, or stereo space.
5. Use silence or a short pause deliberately.

## Translation and loudness
- Avoid maximizing loudness during early composition.
- Leave headroom and compare versions at matched loudness.
- Check the result on headphones, speakers, and a phone where possible.
- Streaming/social-platform processing can vary; do not promise a specific final loudness outcome without platform-specific current requirements.

## Response style
Offer a short ordered checklist, one low-effort experiment, and one more advanced experiment. Explain what each experiment is intended to reveal.
